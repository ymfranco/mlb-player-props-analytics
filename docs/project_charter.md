# Project Charter

## Project Name

MLB Player Props Analytics

---

## Vision

Build an end-to-end decision support platform for evaluating MLB player props using SQL, Python, Excel, Power BI, Statistics and Machine Learning.

---

## Problem Statement

Sports betting decisions are often based on multiple sources of information.

The objective of this project is to centralize relevant historical performance, matchup information and betting market data into a single analytics platform that supports decision making.

---

## MVP

Pitcher Strikeout Decision Engine

The first version of the platform will focus exclusively on evaluating MLB pitcher strikeout props.

---

## Future Modules

- Hitter Total Bases
- Hitter HR + R + RBI
- Model Performance Dashboard
- Machine Learning Models
- Automated Daily Reports
