# Franco Analytics

## MLB Player Props Analytics

An end-to-end data analytics project focused on evaluating MLB player prop opportunities using historical performance, matchup analysis, betting market information and statistical modeling.

This project is part of my Data Analytics portfolio and is being developed while pursuing my Master's in Data Science.

---

## Project Goal

Build a decision-support platform that helps evaluate MLB player props through data-driven analysis.

Rather than making betting recommendations, the objective is to organize and analyze relevant information that supports better decision making.

---

## Current Modules

### ⚾ Pitcher Strikeout Decision Engine (In Development)

The first module focuses on evaluating strikeout props using variables such as:

- Strikeout Percentage (K%)
- Opponent Strikeout %
- Average Batters Faced
- Average Innings Pitched
- Strikeout Prop Line
- Outs Prop Line
- Last 5 Games Performance
- Last 10 Games Performance
- Implied Probability
- Model Probability
- Edge

---

### ⚾ Hitter Analytics (Planned)

Future modules will include:

- Total Bases
- HR + R + RBI
- Hits
